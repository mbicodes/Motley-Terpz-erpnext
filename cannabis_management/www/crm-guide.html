AR Enforcement — Blocked Customers

When someone tries to submit a Sales Invoice or Sales Order for a blocked customer, the system intervenes automatically.

What "Blocked" means

A customer is blocked if either condition is true:

ConditionThreshold
Outstanding AR balance exceeds$50,000
Oldest unpaid invoice is overdue by more than60 days
What happens on submit
User typeOutcome
Regular usersHard error — document cannot be submitted. Contact Finance to resolve the balance first.
Admin / System ManagerRed warning shown — admin can proceed but is warned. Use only when Finance has confirmed it is safe.
📣
In both cases, an automatic Slack notification is sent to Matt, Imran, and Nikki with the customer name, document type, submitted-by user, and the reason (balance / aging).
How to unblock a customer
1
Record outstanding payments in ERPNext via Payment Entry against the overdue invoices.
2
The nightly sync will recalculate the AR Status.
3
The block lifts automatically once neither threshold condition is met.

COD Enforcement

If a customer is marked COD Only and someone submits a Sales Invoice for them, Muhammad receives an automatic Slack alert to verify that cash was collected before the invoice posts.

How to mark a customer as COD Only

Open the CRM Lead → Motley Terpz tab → Account Info → check COD Only.

Tolling Pipeline — Access Control

The Tolling pipeline is hidden from most users. Only users with the "CRM Tolling Access" role assigned in ERPNext can see Tolling leads. All other users see Fresh Frozen, Rosin/Solventless, and Retail/Distro normally.

How to grant Tolling access
1
In ERPNext go to: Settings → User → open the user's record.
2
In the Roles table, add the role CRM Tolling Access.
3
Save the user record. Access takes effect immediately.
⚠️
Users without this role will see zero Tolling leads — they are invisible in all views, searches, and reports.

Nightly Sync — How It Works

Every weeknight (Mon–Fri) a background job runs and updates every CRM Lead that has an ERPNext Customer field filled in.

What gets synced
AR Balance, AR Aging Days, AR Status
Last Invoice Date + Amount
Last Payment Date
MTD Revenue, 8-Week Trailing Revenue
Payment Terms
Last Synced timestamp
How to trigger a manual sync
# Sync a single lead from cannabis_management.api.crm_sync import sync_now sync_now("LEAD-0001") # Sync all linked leads sync_now()
